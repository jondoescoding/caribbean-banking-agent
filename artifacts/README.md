# Local artifacts

Generated and investigative files live here instead of the repository root. The category READMEs are tracked; their runtime contents are ignored.

- `logs/` contains redacted application logs.
- `sessions/` contains non-secret Browserbase session metadata and replay references.
- `captures/` contains approved screenshots or DOM captures with personal data removed.
- `reports/` contains generated validation and audit output.
- `cache/` contains Stagehand action caches.
- `scratch/` contains disposable local experiments.

Never store credentials, cookies, unmasked account identifiers, balances, holdings, transactions, or raw authenticated pages in artifacts.
