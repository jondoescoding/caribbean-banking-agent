# Primary sources

- [Future Caribbean buildathon](https://futurecaribbean.com) and [Finance, Payments & MSME Capital track](https://futurecaribbean.com/tracks/financial) provide the event and track context.
- [OpenAI Apps SDK quickstart](https://developers.openai.com/apps-sdk/quickstart), [MCP concepts](https://developers.openai.com/apps-sdk/concepts/mcp-server), [tool planning](https://developers.openai.com/apps-sdk/plan/tools), and [MCP server guide](https://developers.openai.com/apps-sdk/build/mcp-server) define the ChatGPT integration and tool metadata.
- [Browserbase documentation](https://docs.browserbase.com), [Stagehand repository](https://github.com/browserbase/stagehand), [action caching](https://docs.stagehand.dev/v3/best-practices/caching), [speed optimization](https://docs.stagehand.dev/v3/best-practices/speed-optimization), and [prompting practices](https://docs.stagehand.dev/v3/best-practices/prompting-best-practices) define the browser automation layer.
- [OpenWiki](https://github.com/langchain-ai/openwiki) inspired the linked repository-wiki article model; this project uses its own `docs/` graph and does not install OpenWiki.
- [JMMB Moneyline](https://moneyline.jmmb.com/personal/login.php) is the external portal boundary. Do not visit it during automated tests.
