Maintain a practical code wiki for the read-only Caribbean Banking API. Prioritize the five-minute buildathon path, REST contracts, Browserbase and Stagehand behavior, JMMB data semantics, security boundaries, runbooks, testing, and source ownership. Ground every claim in the current repository and recent Git history. Use Beads for unfinished work; use this wiki for durable product and engineering knowledge. Update affected concept pages and their directory indexes in the same change as the code.
