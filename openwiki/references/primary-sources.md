# Primary sources

- [Browserbase documentation](https://docs.browserbase.com) and [Browserbase setup skill](https://browserbase.com/SKILL.md) define CLI, sessions, contexts, observability, and platform behavior.
- [Stagehand repository](https://github.com/browserbase/stagehand) and [Stagehand documentation](https://docs.stagehand.dev) define the TypeScript automation API, caching, prompting, and speed practices.
- [LangChain OpenWiki](https://github.com/langchain-ai/openwiki) and [Google Open Knowledge Format v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) define this wiki's root index, typed concept pages, nested indexes, Markdown links, and repository instructions.
- [Future Caribbean](https://futurecaribbean.com) and its [Finance, Payments & MSME Capital track](https://futurecaribbean.com/tracks/financial) define the buildathon context.
- [Beads](https://github.com/gastownhall/beads) provides repository-local durable task state and dependency tracking.

The JMMB portal is an authenticated private system. Screenshots supplied by the user inform field coverage, but credentials and extracted live data are never wiki sources.
